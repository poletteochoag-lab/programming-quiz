# Programming Fundamentals Quiz

## Descripción
Videojuego interactivo de preguntas y respuestas sobre fundamentos de programación desarrollado en Python, utilizando la librería gráfica Tkinter y los principios de la Programación Orientada a Objetos (POO).

## Instrucciones de Ejecución
Asegúrate de tener Python instalado en tu equipo. Abre tu terminal en la carpeta del proyecto y ejecuta el siguiente comando:

```bash
python main.py
